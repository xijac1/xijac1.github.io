EcoScan: an AI recycling coach that makes waste sorting clear and rewarding.

Full-stack web app powered by Gemini 2.5 Flash that educates users on recyclable materials through AI photo analysis, then gamifies recycling with points, leaderboards, and impact tracking. Scan, learn, recycle.

overview

What it does

EcoScan turns everyday waste into a learning loop: scan an item, get tailored disposal guidance from Gemini, earn points for correct recycling, and track personal impact — built to cut landfill waste one scan at a time.

01

Photo analysis

Classifies scanned items and delivers tailored disposal instructions so users know what to recycle, compost, or trash.

02

Gamified tracker

Earn points for correct recycling and compete on community leaderboards that keep sustainable habits sticky.

03

Facility locator

Discover nearby recycling centers with easy directions powered by Geoapify — guidance that goes beyond the bin.

04

Personal history

Review past scans and visualize environmental impact over time so progress stays visible and motivating.

What using it looks like

Representative TypeScript flow: send a scanned image to the Gemini-powered backend, receive material classification, and return disposal instructions to the UI.

scan.ts 
// EcoScan: classify a scanned item with Gemini
async function analyzeScan(imageBase64: string) {
  const res = await fetch("/api/scan", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ image: imageBase64 }),
  });

  const data = await res.json();
  // { material, bin, instructions, points }
  return data;
}

// Award points + update leaderboard after a correct recycle
await awardPoints(userId, data.points);
