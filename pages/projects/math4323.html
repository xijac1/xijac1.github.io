Obesity Risk Clustering that surfaces lifestyle patterns behind risk.

Obesity affects over 40.3% of US adults (CDC, 2021–2023), with medical costs exceeding $173 billion annually. This project analyzes a UCI dataset of 2,111 individuals and 16 lifestyle/health features to group people into obesity-risk clusters with unsupervised learning.

overview

What it does

Groups individuals from Mexico, Peru, and Colombia into distinct clusters based on lifestyle and health attributes, aligning those clusters with known obesity risk categories using K-Means and Hierarchical Clustering.

01

Data handling

17 variables total: 16 features plus obesity class. Mix of categorical (gender, smoking) and numerical attributes (age 14–61, weight 39–173kg, vegetable frequency, activity hours).

02

EDA insights

Near-equal gender; mostly non-smokers. Weight right-skewed; FCVC bimodal; age peaks at young adults (20–25); FAF often 0–2 hours — many inactive respondents.

03

Clustering prep

Converted categoricals to numeric, scaled all features for equal Euclidean weighting, then compared K-Means and hierarchical methods with validation metrics.

results

Key findings

Optimal K selection, model comparison, and lifestyle patterns that line up with obesity risk — supported by silhouette analysis, gap statistics, and cluster visualizations in the full report.

code

What using it looks like

Representative R workflow: scale features, fit K-Means for a chosen K, run hierarchical clustering, and check cohesion with silhouette scores.

cluster.R 
# Obesity risk: K-Means + hierarchical clustering
library(cluster)

obesity <- read.csv("obesity.csv")
# convert categoricals to numeric, then scale for Euclidean distance
X <- scale(obesity_features)

# K-Means with K selected via gap / elbow / silhouette (K=10)
km <- kmeans(X, centers = 10, nstart = 25)

# Hierarchical clustering + dendrogram structure
hc <- hclust(dist(X), method = "ward.D2")
plot(hc)

# Internal validation
sil <- silhouette(km$cluster, dist(X))
mean(sil[, 3])
