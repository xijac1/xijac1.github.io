O'Hare Air: personalized air-quality guidance that makes every breath count.

Full-stack Next.js app built at HackRice 2025 that delivers personalized air-quality guidance, health-aware recommendations, saved location tracking, and route-oriented run planning. Powered by Google's Air Quality and Weather APIs.

overview

What it does

O'Hare Air turns real-time air quality data into a personal health companion: check your dashboard for local AQI, save places and track their conditions, log symptoms against exposure, and get run-coach recommendations for low-exposure outdoor activity.

01

Dashboard

Shows current location, real-time AQI, weather conditions, saved place summaries, and personalized risk thresholds based on your health profile.

02

Health profile

Set asthma, cardiopulmonary disease, pregnancy, age sensitivity, and lifestyle risk flags to tighten AQI thresholds and tailor guidance.

03

Saved places

Add, rename, and delete places with Google Maps autocomplete. Each saved place is refreshed with live AQI, risk, outlook, and pollutant details.

04

Run coach

Suggests route direction, time window, duration, and warning summary to guide outdoor activity toward lower-exposure conditions.

What using it looks like

Representative Next.js API route: fetch air quality for a given lat/lng from the Express backend proxy and return AQI, risk, and health recommendations to the dashboard.

route.ts 
// O'Hare Air: fetch air quality for dashboard
export async function GET(req: NextRequest) {
  const { lat, lng } = Object.fromEntries(
    req.nextUrl.searchParams
  );

  const res = await fetch(`${BACKEND_URL}/api/air-quality?lat=${lat}&lng=${lng}`);
  const data = await res.json();

  // { aqi, risk, pollutants, recommendations }
  return NextResponse.json(data);
}
