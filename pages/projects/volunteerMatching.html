VolunteerMatch: a full-stack volunteer management platform that makes coordinating service seamless.

Full-stack web application for managing volunteers, events, and administrative workflows. Features role-based access control, real-time notifications, event management, volunteer matching, and reporting. Streamlines how organizations manage their volunteers.

overview

What it does

VolunteerMatch turns volunteer coordination into a guided experience: volunteers register, complete profiles, track their history, and receive notifications — while administrators manage events, match volunteers to opportunities, and access analytics dashboards. Built with role-aware routing and a demo mode for easy exploration.

01

Authentication & access control

Firebase-powered login and registration with React Router route guards for private pages, profile-completion flows, and admin-only areas.

02

Volunteer experience

Homepage, profile management, notifications, and volunteer history with a persistent navbar and role-aware navigation.

03

Administrator tools

Event management, volunteer matching, and an admin dashboard — all hidden from regular volunteers behind role-based guards.

04

Notifications & reporting

Firebase Cloud Messaging for in-app notifications, plus PDF and CSV export workflows for admin reporting and operational summaries.

What using it looks like

Representative React component: role-based route guard that checks authentication state and user role before granting access to admin pages.

auth.tsx 
// VolunteerMatch: role-based route guard
function AdminRoute({ children }) {
  const { user, role } = useAuth();
  const navigate = useNavigate();

  if (!user) {
    return <Navigate to="/login" />;
  }

  if (role !== "admin" && role !== "administrator") {
    return <Navigate to="/dashboard" />;
  }

  return children;
}
