Heart Disease Classification that finds what actually predicts risk.

Heart disease is the leading cause of death in the US (CDC, 2022), claiming a life every 33 seconds. This project uses a UCI dataset of 303 patients and 13 clinical features to build binary classification models that predict heart disease presence.

overview

What it does

Built on the UCI Heart Disease dataset (Cleveland, Hungary, Switzerland, VA Long Beach), the project identifies key predictors, compares Logistic Regression vs. Random Forest, and answers: which features matter most, which model is best, whether age matters, and whether disease is more common in males. Built by Group 5: Almin Raja, Dinh Mai, Julio Amaya, Subhan Mehmood, Nicholas Pham.

01

Data handling

14 variables total: 13 predictors plus binary response num. Mix of categorical features (sex, chest pain type) and numerical ones (age, cholesterol) prepared for modeling.

02

Logistic Regression

Optimal model with 8 significant predictors (sex, cp, trestbps, thalach, exang, slope, ca, thal). 82.46% accuracy via 10-fold cross-validation.

03

Random Forest

500 trees for non-linear structure; 80.33% accuracy on the full model. Top features by importance: ca, thal, and cp.

code

What using it looks like

Representative R workflow: load the UCI CSV, fit logistic regression and a 500-tree random forest, then evaluate with cross-validation and feature importance.

model.R 
# Heart disease: logistic regression + random forest
library(randomForest)

heart <- read.csv("heart.csv")
heart$num <- factor(heart$num > 0)  # binary: disease yes/no

# Optimal logistic model (8 significant predictors)
logit <- glm(
  num ~ sex + cp + trestbps + thalach + exang + slope + ca + thal,
  data = heart,
  family = binomial()
)

# Random forest: 500 trees, full feature set
rf <- randomForest(num ~ ., data = heart, ntree = 500)
varImpPlot(rf)  # ca, thal, cp dominate importance

# 10-fold CV accuracy ~82.46% (logit) vs ~80.33% (rf)
print(summary(logit))
